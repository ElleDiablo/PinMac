# Security

PinMac uses Screen Recording and Accessibility permissions, so security
reports matter.

**Please don't report security problems in public issues.** Instead, use
[GitHub's private vulnerability reporting](../../security/advisories/new)
for this repository.

Include what you found, how to reproduce it, and which PinMac and macOS
versions are affected. You'll get a reply as soon as possible.

Only the latest release receives security fixes.
